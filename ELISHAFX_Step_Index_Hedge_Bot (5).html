Start here — simple setup guide

  1. Open this HTML file in Chrome while you have internet.
  2. On Deriv, create an API token with Read and Trade permissions. Use a demo account token only.
  3. Paste the token below, choose Connect, and wait for “DEMO ACCOUNT VERIFIED”.
  4. Confirm Step Index 100 is selected, duration is 2 ticks, and stake is 0.35.
  5. Press BUY BOTH only when ready. Check the activity log and contract cards afterward.

This version is demo-only: it will not enable buying unless Deriv identifies the authorized login as a demo account. Never share your API token with anyone.
